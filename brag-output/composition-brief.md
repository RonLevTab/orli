# Hyperframes Composition Brief: אורלי (Orli)

## Objective
A short sales video that gets a clinic owner to book a demo.

## Output
- Composition directory: `brag-output/composition/`
- Rendered video: `brag-output/brag.mp4`
- Format: vertical — 1080x1920
- Duration: 24.8 seconds

## Source Material
- Project root: `orli/` (marketing site for orli-calendar)
- Primary files read: index.html, styles.css, widget.css, widget.js, integration.html, PRODUCT.md
- Product name: אורלי
- Strongest claim: הפגישה נכנסת ישירות לאופטימה, בלי הקלדה
- Key UI to recreate: the booking widget (practitioner → time → code → booked) and the "היומן באופטימה" calendar
- Copy that must appear verbatim:
  - הפכו את יומן האופטימה למנוע קביעת פגישות.
  - בלי הקלדה. בלי טלפונים חוזרים.
  - הפגישה נקבעה! / אישור נשלח לאימייל
  - בחרו שעה להדגמה

## Creative Direction
- Tone preset: polished
- Creative direction: warm flat-vector illustration + real UI motion, Hebrew RTL throughout
- Angle / hook / outro: see `brag-plan.md`
- Avoid: generic SaaS language, abstract filler, statistics on screen, any redesign of the widget

## Visual Identity
- Background #f7f5ef, night #16211f, text #1b2523, accent #0f8a86 / #0a5d5a / #14b8a6, line #e4ddcf, surface #fffdf8
- Fonts: Heebo (local woff2 in assets/fonts)
- References: site hero calendar mock, widget tokens (--obw-*), brand wordmark

## Storyboard
Contract is `brag-plan.md`.
1. Closed clinic — 3.5s — night illustration + hook question
2. Missed calls — 3.1s — three cards + "תא קולי לא קובע פגישות."
3. Patient books — 6.3s — widget flow on a phone
4. Optima fills itself — 6.6s — four appointments drop in, secretary with coffee
5. The close — 5.3s — claim, one-line snippet, wordmark + CTA
